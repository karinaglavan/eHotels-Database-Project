Description:
This project is an eHotels database and web application developed using MySQL, SQL, Node.js, Express, HTML, CSS, and JavaScript.

The database includes hotel chains, hotels, rooms, customers, employees, bookings, rentings, archives, indexes, views, triggers, and populated sample data.

The web application allows users to filter room information to select a hotel room for booking, edit bookings, create rentings, and add/delete/update data in editable tables in the eHotels database.
